# Notesnook Desktop App rewrite

- TailwindCSS and TypeScript
- Glassmorphism and modern design patterns
- Electron
- Sidebar left
  - All Notes
  - Notebooks and Subnotebooks
    - ability to set icons for a notebook
    - sortable notebooks
  - Tags and Subtags
    - ability to set icons for a tag
    - sortable tags
  - Trash (with ability to restore notes) at the bottom of the sidebar
  - Monographs
  - Archive
  - Settings
    - should be implemented as a seperate window
  - Sync Status
  - Update Notifier at the bottom of the sidebar
  - Shortcuts
    - Every notebook, tag or note can get set as a shortcut
      - a shortcut can have a custom color and icon
- Notes List
  - Search bar at the top with regex support
  - Sortable notes by title, date created, date modified, and custom order
  - grouping by dates, notebooks, tags, and custom groups (groups setable)
  - on top of the notes list, there should be a "New Note" button on the right and a collapse sidebar button on the left that collapses / expands the sidebar
  - Entry in the notes list should show the note title, first line of the note, date created, date modified, and tags
    - if it contains checkboxes from TipTap it also should display a progress bar with x / y checked boxes
  - if a note contains an image, the first one should be displayed as a thumbnail in the notes list entry
- Note Editor
  - based on TipTap like the Notesnook app here
  - Tab support for switching between notes
    - should be splittable like VS Code
  - Tabs should be sortable and closable
  - dragging a tab out of the window creates a new window with that note
    - the new window should also have the same features as the main window but by default open in focus mode (without sidebar and notes list open)
  - Feature Parity with the Notesnook desktop app in terms of editing and the edit toolbar
    - toolbar should also contain undo / redo, search and ToC
      - ToC (Table of Contents) will display as a MiniMap on the right side of the editor
  - ... Menu for all the features that are not available in the toolbar like
    - Properties will display as right Sidebar with the following properties:
      - Title
      - Notebook
      - Tags
      - Created Date
      - Modified Date
      - Word count
      - Character count
      - Line count
      - some toggles
        - Pin
        - Favorite
        - Lock
        - Read Only
        - Archive
        - Disable Sync
        - Spell Check
      - Publish (to Monograph)
      - Linked Notes (in and out)
      - History
